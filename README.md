# 👓 Projeto Google Glass

![Status do Projeto](https://img.shields.io/badge/Status-Conclu%C3%ADdo-brightgreen?style=for-the-badge)
![License](https://img.shields.io/badge/License-MIT-blue?style=for-the-badge)

Bem-vindo ao repositório do projeto **Google Glass**, um portal interativo desenvolvido para explorar as funcionalidades, especificações técnicas e a história do ambicioso gadget da Google. Este projeto foca em semântica HTML5, estilização avançada com CSS3 e interatividade via JavaScript puro. 
Desenvolvido durante o curso de HTML5 e CSS3 do Curso em Vídeo!

---

## Tecnologias Utilizadas

*   ![HTML5](https://img.shields.io/badge/html5-%23E34F26.svg?style=for-the-badge&logo=html5&logoColor=white) - Estruturação semântica e acessibilidade.
*   ![CSS3](https://img.shields.io/badge/css3-%231572B6.svg?style=for-the-badge&logo=css3&logoColor=white) - Design responsivo, tipografia personalizada e layouts complexos.
*   ![JavaScript](https://img.shields.io/badge/javascript-%23F7DF1E.svg?style=for-the-badge&logo=javascript&logoColor=black) - Controle de mídia, interatividade de menus e validação de formulários.

---

## Funcionalidades

-   **Interface Multimídia**: Player de áudio e vídeo integrado suportando múltiplos formatos (`.mp3`, `.ogg`, `.mp4`, `.webm`).
-   **Galeria Interativa**: Visualização de imagens com efeitos de hover e scripts dinâmicos.
-   **Mapa de Especificações**: Detalhamento técnico do hardware do dispositivo.
-   **Formulário de Contato**: Interface completa para captação de dados com validação.
-   **Design Responsivo**: Adaptabilidade para diferentes tamanhos de tela (Mobile e Desktop).

---

## Estrutura de Diretórios

A organização do projeto segue uma lógica modular para facilitar a manutenção:

```text
├── _interface/    # Mockups e diagramas de divisão semântica
├── _javascript/   # Scripts de comportamento e funções globais
├── _media/        # Arquivos brutos de áudio e vídeo
├── css/           # Estilização modular (form, fotos, specs, mobile)
├── fonts/         # Tipografias customizadas (Bubblegum Sans, Computer Font)
├── imagens/       # Assets visuais e ícones da interface
└── *.html         # Páginas principais do portal
```

## 🛠️ Como Executar o Projeto

1.  **Clonar o repositório:**
    ```bash
    git clone https://github.com/flaviare1s/projeto-glass-html5.git
    ```

2.  **Acessar a pasta:**
    ```bash
    cd projeto-glass-html5
    ```

3.  **Abrir o projeto:**
    Basta abrir o arquivo `index.html` em qualquer navegador moderno. 
    *Dica: Utilize a extensão **Live Server** no VS Code para uma melhor experiência de desenvolvimento.*

## 📸 Demonstração do Fluxo

O projeto é dividido em diferentes sessões estratégicas:
1.  **Home**: Visão geral e introdução ao produto.
2.  **Especificações**: Detalhes técnicos sobre tela, câmera e bateria.
3.  **Fotos**: Galeria visual do gadget.
4.  **Multimídia**: Experiência auditiva e visual com vídeos oficiais.
5.  **Fale Conosco**: Canal de comunicação direta.
